# 발품 노트

서울 동부 실거주 임장 체크리스트. 정적 웹사이트로, 기록은 브라우저 localStorage에만 저장됩니다. 계정·서버 동기화는 없습니다.

- 매물 이름/주소/가격/면적을 추가하고 49개 항목을 체크
- 현장 메모, 방문 시각, 통근, 100점 점수표
- HTTPS 위치 권한으로 현재 위치와 후보 직선거리 확인; 현장에서 매물 좌표 저장
- 지도·대중교통 길찾기, JSON 백업/복원

브라우저 데이터 삭제나 다른 기기 접속 시 기록이 이어지지 않습니다. 백업 파일을 수시로 내려받으세요. 매물 가격과 정보는 2026-10-16 조사 당시 참고값이며 변경될 수 있습니다.
